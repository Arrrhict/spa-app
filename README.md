# SPA App

Учебное одностраничное приложение (вариант 4, практическая работа № 12).

## Стек
- HTML / CSS / JavaScript (SPA-роутинг на History API)
- Apache (XAMPP) + mod_rewrite

## Запуск в XAMPP
1. Проект расположен в `C:\xampp\htdocs\spa-app`.
2. Включён `mod_rewrite`, для `htdocs` стоит `AllowOverride All`.
3. Apache перезапущен.
4. Открыть http://localhost/spa-app/public/

## Структура
- `public/` — точка входа, `.htaccess` для SPA-роутинга
- `src/` — исходники приложения
- `docs/` — документация
